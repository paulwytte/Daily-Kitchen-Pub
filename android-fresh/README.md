# Daily Kitchen & Pub Android App

Fresh rebuild for Daily Kitchen & Pub.

Features:
- Home and branding
- Complete food menu and prices
- Complete drinks menu and prices
- Food photo gallery
- Shopping cart
- Customer name and phone
- Pickup or delivery
- Delivery address
- Order notes
- Automatic total
- WhatsApp checkout
- Restaurant call
- Official website
- Catering booking
- Saturday special

This repository build uses GitHub Actions with Gradle 8.9.
